# Планировщик задач (Go Final Project)

Веб-сервер на Go — аналог TODO-листа. Задачи хранятся в SQLite, есть REST API
и готовый фронтенд.

## Что умеет

- Добавлять, редактировать, удалять задачи
- Отмечать задачу выполненной (повторяющаяся переносится на следующую дату,
  обычная удаляется)
- Повторяющиеся задачи: каждые N дней, ежегодно, по дням недели, по дням месяца
- Поиск по задачам

## Запуск

```bash
go run .
```

Открыть в браузере: **http://localhost:7540/**

Переменные окружения (необязательно):

| Переменная | По умолчанию | Назначение |
|------------|--------------|-----------|
| `TODO_PORT` | `7540` | порт сервера |
| `TODO_DBFILE` | `scheduler.db` | путь к файлу БД |

Пример: `TODO_PORT=8080 go run .` → http://localhost:8080/

БД создаётся автоматически при первом запуске.

## Тесты

Сначала запустите сервер в отдельном окне:

```bash
# окно 1
go run .

# окно 2, из корня проекта
go test ./tests
```

Параметры для заданий со * нужно включать тесты в `tests/settings.go`: `FullNextDate = false`, `Search = false`.
Для полной проверки (правила `w`/`m` и поиск) временно поставьте `true` и верните
обратно после прогона.

`TestDB` поднимает свой сервер — перед ним ручной нужно остановить, иначе
`database is locked`.

## Docker

```bash
docker build -t go-final-project .
mkdir -p data
docker run -d --name scheduler -p 7540:7540 \
  -v "$(pwd)/data:/data" \
  -e TODO_DBFILE=/data/scheduler.db \
  go-final-project
```

Открыть: http://localhost:7540/

Остановить: `docker stop scheduler && docker rm scheduler`
